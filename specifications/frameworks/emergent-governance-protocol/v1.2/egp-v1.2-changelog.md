- Migrated the controlling interface from GMEAIA/0.1 to GMEAIA/0.2.1.
- Preserved the three public operations and ten adoption effect labels.
- Added CP0–CP3 consequence-profile claims and validation.
- Added causal responsibility, authority formation, and jointly constituted authority references.
- Added exact GMEAIA handoff states and response/action-clock references.
- Separated capacity limitation from constitutional absence.
- Added minimum causal adequacy to consequential proposals.
- Added response omission and post-acceptance performance-omission semantics.
- Added CP3 specialized-interface and protected-domain authorization requirements.
- Strengthened correction, closure, unresolved-duty custody, and data disposition.
- Replaced the obsolete IAEG-CLUSTER/0.1 adoption block with transition-registry compatibility.
- Added a new JSON Schema and three canonical examples.
