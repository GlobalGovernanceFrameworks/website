# Stakeholder Value System Matrix – SDTP & Global Governance Frameworks

**Legend:**
- **Primary** = dominant mode of operation (how they typically think and act)
- **Secondary** = accessible mode (where alignment can be built)
- **Resistant** = mode that will likely reject unless carefully framed

---
